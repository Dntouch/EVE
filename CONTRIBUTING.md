# Beiträge zu EVE

Dieses Dokument ist eine Orientierung für Änderungen am Repository. Ein darüber
hinausgehender Beitrags- oder Freigabeprozess ist noch nicht festgelegt.

## Inhaltliche Grundlage

Das [EVE-Konzept](docs/konzept/EVE-Konzept.md) ist die inhaltliche Grundlage des
Repositories. Ergänzende Dokumente sind als Zusammenfassung des Konzepts,
bestätigte Entscheidung oder Vorlage gekennzeichnet.

## Änderungen beschreiben

Ein Pull Request kann kurz festhalten:

- was geändert wurde,
- warum die Änderung vorgeschlagen wird,
- auf welchen Abschnitt des Konzepts sie sich bezieht,
- welche Fragen offenbleiben.

Die vorhandenen Issue- und Pull-Request-Vorlagen können dafür verwendet werden.

## Git

Für Branch- und Commit-Namen enthält das Repository Vorschläge. Sie sind keine
inhaltlichen Projektentscheidungen:

- mögliche Branch-Präfixe: `docs/`, `research/`, `decision/`, `experiment/`
- mögliche Commit-Typen: `docs`, `research`, `decision`, `experiment`, `chore`
