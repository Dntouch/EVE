# 0001 – Dokumentationsorientierter Projektstart

**Datum:** 2026-11-15

## Kontext

Für EVE wurde ein sauber aufgesetztes und für Git vorbereitetes Projekt
gewünscht. Auf Nachfrage wurde ausdrücklich klargestellt, dass dabei keine
Software gebaut werden soll.

## Bestätigte Entscheidung

Der erste Stand des Repositories enthält Projektorganisation und Dokumentation,
aber keinen Programmcode.
