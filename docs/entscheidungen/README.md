# Entscheidungsprotokolle

Entscheidungsprotokolle halten grundlegende oder schwer umkehrbare Entscheidungen
mitsamt Kontext und Folgen fest. Sie verhindern, dass spätere Arbeit auf
unsichtbaren Annahmen beruht.

## Dateinamen

```text
NNNN-kurzer-titel.md
```

Die Nummer bleibt dauerhaft erhalten. Ein angenommenes Protokoll wird nicht
inhaltlich umgedeutet. Eine neue Entscheidung kann es ausdrücklich ersetzen.

## Status

- Entwurf
- In Prüfung
- Angenommen
- Verworfen
- Ersetzt durch NNNN

## Ablauf

1. Vorlage kopieren und nächste freie Nummer vergeben.
2. Kontext, Entscheidungskriterien und echte Alternativen beschreiben.
3. Konsequenzen einschließlich Nachteile dokumentieren.
4. Verknüpfte Forschungsfragen, Experimente und Risiken angeben.
5. Prüfung durchführen und Status aktualisieren.
