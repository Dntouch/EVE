# Entscheidungsprotokolle

Dieser Ordner enthält bestätigte Entscheidungen zum Projekt sowie eine optionale
[Vorlage](VORLAGE.md) für weitere Entscheidungen.

## Bestätigte Entscheidungen

| Nummer | Entscheidung |
|---|---|
| [0001](0001-dokumentationsorientierter-projektstart.md) | Der erste Repository-Stand enthält Projektorganisation und keinen Programmcode. |
| [0003](0003-projektname-eve.md) | Der offizielle Projektname lautet EVE. |
| [0011](0011-keine-freigabe-fuer-b4-nach-b31.md) | B.3.1 genügt nicht für allgemeine rückmeldungsabhängige Gewichtsänderung. |
| [0012](0012-isolierter-drei-faktor-versuch-b4.md) | B.4 darf als begrenzter Drei-Faktor-Versuch laufen; die Produktionssperre bleibt bestehen. |

| [0014](0014-begrenztes-einzelreiz-lernen-nach-b42.md) | Geschützte Exploration ermöglicht begrenztes Einzelreiz- und Umkehrlernen; eine allgemeine Freigabe erfolgt nicht. |
| [0015](0015-keine-freigabe-mehrfachlernen-nach-b43.md) | B.4.3 weist synaptische Interferenz und starkes Vergessen nach; Mehrfachlernen wird nicht freigegeben. |

| [0017](0017-motorische-konkurrenz-nach-b45.md) | B.4.5 weist konkurrierende Motoraktivität als nächsten lokalen Engpass aus; eine inhibitorische Forschungsvariante wird erst für B.4.6 vorbereitet. |
| [0018](0018-inhibitorische-grundfunktion-bleibt-experimentell.md) | B.4.6 bestätigt lokale Hemmung technisch, lässt sie wegen unzureichender Robustheit und Zuordnungsbias aber experimentell. |

Nummer 0002 wurde entfernt. Die vorübergehende Nichtwahl eines Technologie-Stacks
war keine bestätigte langfristige Projektentscheidung. Die Nummern 0004 bis
0010 sind dokumentierte Übergangsvorlagen und keine abgeschlossenen Freigaben.
